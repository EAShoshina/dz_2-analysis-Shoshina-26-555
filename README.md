# Primitive DB
Примитивная база данных

## Установка и запуск

```bash
# Сборка пакета
uv build

# Установка как CLI-инструмента
uv tool install dist/primitive_db-0.1.0-py3-none-any.whl

# Запуск
database
```

## 1 этап: Инициализация пакета
Проект настроен как устанавливаемый пакет (wheel) с точкой входа `database`. Использует `uv` для управления зависимостями и окружением.

## Этап 2: База данных (Управление таблицами)

Реализовано ядро базы данных с сохранением метаданных в JSON-файл (`db_meta.json`).

*   **`create_table`** — создание таблиц с типами (`int`, `str`, `bool`). Автоматически добавляется `ID:int`.
*   **`list_tables`** — просмотр списка таблиц.
*   **`drop_table`** — удаление таблиц.

## Этап 3: CRUD-операции
Реализован полный набор операций с данными (в отдельных JSON-файлах `data/<table_name>.json`):

*   **`insert`** — добавление записей (с валидацией типов и автогенерацией ID).
*   **`select`** — чтение данных с фильтрацией (`where`) и без.
*   **`update`** — обновление записей по условию.
*   **`delete`** — удаление записей по условию.
*   **`info`** — вывод информации о таблице.

Для красивого вывода используется библиотека `prettytable`.

### Этап 4: Декораторы и замыкания

*   **`handle_db_errors`** — централизованная обработка ошибок (`FileNotFoundError`, `KeyError`, `ValueError` и др.).
*   **`confirm_action`** — запрос подтверждения (`[y/n]`) перед опасными операциями (`drop_table`, `delete`).
*   **`log_time`** — замер времени выполнения `insert` и `select`.
*   **`create_cacher`** — замыкание для кэширования `select`. Повторные запросы с теми же условиями возвращаются мгновенно. Кэш сбрасывается при изменении данных.
